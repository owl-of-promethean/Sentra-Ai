Step 4 — Copilot AI

Context-aware answers.
Not a generic chatbot.

Select an investigation or audit, then ask Copilot targeted questions. The backend validates the context object before every call. Groq receives only the relevant Sentra security data — never arbitrary prompts.

Security boundary

The model receives a system instruction that restricts it to the supplied security context. General-purpose questions, off-topic requests, and prompt injection attempts are refused by the model, not just the UI.
